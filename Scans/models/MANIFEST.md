# Scans — Muse version models: manifest

A separate 3D model (the **Muse version**) for every illustration cataloged in `Scans/catalog.json`, built 2026-11-01/02. Each model was built from its scan + catalog description as the primary references; single-view subjects use flagged historical interpretation for unseen sides; repaired scan areas (figs 43, 54, 74) were treated as approximate, never as evidence. People are stylised period-dress forms — no likenesses, no caricature. Every preview was audited against its reference image.

**49 of 49 catalog entries modelled.** No entry skipped. The three unrepaired variant crops (figs 43/54/74) are the same subjects as their repaired versions and are accounted for by those entries.

Two duplicate draft folders produced by a parallel build stream (`scan-fig56-cannibal-islanders-caricature`, `scan-fig57-chinese-commission-frontispiece`) were NOT shipped; the versions below are the audited ones.
