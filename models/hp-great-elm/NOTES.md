# NOTES — Great elm (procedural, generic)

Prop for the Crystal Palace film. Hyde Park 1851 building only.

## What it is

A generic mature English elm silhouette for instancing in
transept scenes (CP018–CP023, where the building encloses the
park's elms). Trunk, five primary branches with one split each,
and icosphere foliage blobs. Origin at ground centre (trunk
base). Units: metres. Blender 4.2+. Seeded random (1851), so
re-runs are identical.

## Dimensions — all guessed

No dimensioned elm was found in the repo references. Transept
interior views show elms enclosed by the building, but no height,
girth or crown measurement for any individual tree was found in
the Downes controls, the 1856 guide dimensions, or the manifest
image set checked for this prop.

| Part | Value | Status |
|---|---|---|
| Total height | 18 m | Guessed |
| Clear trunk | 5 m | Guessed |
| Trunk base diameter | 0.9 m, tapering to 0.5 m | Guessed |
| Primary branches | 5, split once each | Modelling choice |
| Crown spread | ~12 m across | Follows from the guessed branch lengths |
| Leaf colour / form | Flat green blobs, two tones | Interpretive — a silhouette aid, not foliage botany |

## What this prop must NOT be used for

- Never caption it as a particular transept elm, and never
  quote its 18 m height as a measured fact. It is a generic
  mature-elm stand-in.
- Not a botanical model: no leaf shape, bark texture, root
  flare or seasonal state is claimed.
- Do not place it as a Sydenham tree — Sydenham's grounds
  planting is a different, later landscape.
