# The Crystal Palace

Reference library, Blender scenes and course models for the 1851 Crystal Palace.

| Folder | What it is |
|---|---|
| `references/` | Research images and sources: `muse-drive/` (1,393 images + manifest with source URLs and licences), `downes-1852/` (working drawings), `image-leads/`, `walker-research-notes/` |
| `blender-deliverables/` | Reduced Blender scene, renders, comparisons, build notes |
| `course-models/` | Course export of the model |
| `maps/` | Texture maps |
| `models/` | **New 3D models made by Muse from the reference images** (see `MUSE-PROMPT.md`) |
| `crystal/` | Book text (`crystal.md`) and images |

Left out of the repo (over GitHub's 100 MB limit, kept locally): the full-resolution `.blend` (234 MB), `maps.zip`, the audiobook MP3, and two `.zip` scan archives.

Image licences vary by source; see `references/muse-drive/data/manifest.csv` (`license` column) before reusing anything outside the course.
