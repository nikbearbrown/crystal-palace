# Grok Models for Crystal Palace Illustrations

This branch contains modeling briefs, concept preview renders, and simple proxy meshes generated by Grok for the 49 cataloged images in `scans/crystal-palace-illustrations-2026-11-01`.

## Contents
- `modeling_briefs/` — Full briefs for all 49 images (Markdown + JSON)
- `previews/` — Concept/preview images of intended 3D models
- `proxies/` — Simple geometric proxy GLBs (importable into Blender)
- `manifest/progress.json` — Current progress

## Notes
Full high-fidelity editable Blender models are not generated here. These are high-quality concept previews plus basic proxies. Scale is estimated. Unseen sides use historically informed interpretation.

Source scans and catalog are preserved from the parent branch.
