Crystal Palace — prepared for Nik Bear Brown

Open crystal-palace-full.blend in Blender 5.1.2.
This full-resolution scene preserves all 6,832,098 source polygons.
Ten texture images are packed inside the file; four cameras and daylight lighting are included.
full-resolution-preview.png is an actual Cycles render of this file.

The blender-deliverables folder contains the reduced Blender scene, renders, comparisons, build notes and an offline gallery.
Map assignments were reconstructed from the supplied maps; original Corona/Scanline shaders were not preserved.
The source FBX, MAX, 3DS and DWG models and both local GLB exports were removed at Nik Bear Brown’s request. All four Blender files and the maps are preserved. Historical build notes and mirrored documentation may still describe the removed formats; the GitHub course repository was not changed by this local cleanup.
